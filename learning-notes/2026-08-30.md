For each future unique PR:

```bash
git switch main
git pull --ff-only origin main
git switch -c learning/YYYY-MM-DD-topic
```

Make your changes, then:

```bash
git status
git diff
git add .
git diff --staged
git commit -m "Describe what I learned"
git push -u origin learning/YYYY-MM-DD-topic
gh pr create --base main --fill
```

Each new branch name creates a separate pull request. Do not reuse an old branch if you want a new PR.
